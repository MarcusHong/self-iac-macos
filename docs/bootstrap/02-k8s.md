# K8s 워크로드

OrbStack K8s 위에 올라가는 워크로드들. 호스트 데이터 레이어에 의존한다.

## 실행

```bash
# GitLab 제외 (기본값)
./bootstrap/02-k8s.sh

# GitLab 포함 (01-data.sh도 같은 값으로 실행했어야 함)
INSTALL_GITLAB=true ./bootstrap/02-k8s.sh
```

## 설치 순서

| 순서 | 컴포넌트 | 네임스페이스 | 차트 버전 | 용도 |
|:---:|---------|:----------:|:--------:|------|
| 1 | Traefik | traefik | 42.0.0 (v3.7.14) | Ingress + TLS 종단 |
| 2 | GitLab CE (선택) | gitlab | 10.5.0 (19.5.0) | Git + CI/CD + Registry |
| 3 | Argo CD | argocd | 10.10.5 (v3.5.5) | GitOps 동기화 |

차트 버전은 `02-k8s.sh` 상단의 `*_CHART_VERSION` 변수로 고정되어 있다.

## 1. Traefik

K8s Ingress Controller. Tailscale 인증서를 사용하여 HTTPS를 종단한다.

| 포트 | 용도 |
|:----:|------|
| 80 | HTTP (HTTPS로 리다이렉트) |
| 443 | HTTPS |

컨테이너는 non-root로 8000/8443에서 리슨하고, LoadBalancer Service가 80/443으로 노출한다.
TLS Secret은 `traefik` 네임스페이스의 `tailscale-tls`에 저장된다.

## 2. GitLab CE (선택)

`INSTALL_GITLAB=true`일 때만 설치한다. Helm chart로 배포하며 모든 stateful 컴포넌트는 호스트를 사용한다.

**Ingress:** 차트 10.x(GitLab 19)부터 기본값이 Gateway API + Envoy Gateway로 바뀌었다.
`gitlab-values.yaml`에서 `global.gatewayApi.enabled/installEnvoy: false`, `global.ingress.enabled: true`,
`global.ingress.provider: traefik`으로 Traefik Ingress를 사용한다.

**비활성화한 서브차트:**
- Nginx Ingress, Envoy Gateway → Traefik 사용
- cert-manager → Tailscale TLS 사용
- Prometheus → 비활성화
- (PostgreSQL/Redis/MinIO 번들 서브차트는 차트 10.x에서 제거됨 — 호스트 서비스 사용)

**활성화된 컴포넌트:**
- Webservice (Puma 1 worker)
- Sidekiq
- Gitaly (50GB PV)
- Runner (K8s executor, privileged, 기본 이미지 `ubuntu:26.04`)
- Container Registry
- Toolbox (일일 자동 백업)

**오브젝트 스토리지 (호스트 Garage):**

OpenBao `infra/garage`의 `gitlab` 키로 아래 Secret을 만든다. 형식은 GitLab 차트 문서의 Garage 예시를 따른다.

| Secret (gitlab ns) | 키 | 사용처 |
|--------------------|----|--------|
| `gitlab-object-storage` | `connection` | Rails/Workhorse (fog, `path_style: true`, 리전 `garage`) |
| `gitlab-object-storage-s3cmd` | `config` | Toolbox 백업/복원 (s3cmd 설정 형식) |
| `gitlab-registry-storage` | `config` | Registry (`s3` = s3_v2 드라이버, `pathstyle: true`) |
| `gitlab-runner-cache-secret` | `accesskey`, `secretkey` | Runner 캐시 (`[runners.cache.s3]`는 values의 `runners.config`) |

`host.docker.internal:3900`은 클러스터 밖에서 접근할 수 없으므로 `proxy_download: true`와
Registry `storage.redirect.disable: true`로 다운로드를 GitLab/Registry가 직접 전달한다.

**기존 설치 업그레이드:** GitLab은 [필수 업그레이드 경로](https://docs.gitlab.com/update/upgrade_paths/)를
지켜야 한다. 이전 메이저(18.x)에서 바로 19.5로 올리지 말고 필수 정지 버전을 차례로 거친다.

**SMTP (Gmail):**

`SMTP_USER`와 `SMTP_PASSWORD` 환경변수를 설정하면 Gmail SMTP로 메일을 발송한다.
Google 앱 비밀번호 필요 (https://myaccount.google.com/apppasswords).

```bash
export SMTP_USER="your@gmail.com"
export SMTP_PASSWORD="앱비밀번호"
```

**자동화 스케줄:**

| 작업 | 스케줄 | 설명 |
|------|--------|------|
| GitLab 백업 | 매일 04:00 | Garage `gitlab-backups` 버킷에 저장 |
| Registry GC | 매주 일 05:00 | 미사용 이미지 레이어 정리 |
| TLS 인증서 갱신 | 격월 1일 03:00 | Tailscale 인증서 자동 갱신 (GitLab과 무관하게 항상) |

**호스트 연결:** K8s에서 호스트 서비스에 `host.docker.internal`로 접근한다 (OrbStack 제공).

**초기 root 비밀번호:**

```bash
kubectl get secret gitlab-gitlab-initial-root-password \
  -n gitlab -ojsonpath='{.data.password}' | base64 -d; echo
```

스크립트가 자동으로 OpenBao `infra/gitlab`에도 저장한다.

## 3. Argo CD

builders-starter-iac와 같은 구성이다. 자세한 운영은 [Argo CD 운영](../argocd.md) 참고.

- Helm으로 설치 (`bootstrap/argocd-values.yaml`): Dex 비활성화, ApplicationSet replica 0,
  Notifications 활성화, `timeout.reconciliation: 60s`, OCI layer media type 지정
- 설치 직후 `./k8s/deploy.sh`로 `k8s/`를 직접 적용: `apps` Namespace, AppProject(`platform`, `apps`),
  Argo CD Ingress, 서비스별 OCI Application
- 이 저장소와 `k8s/`는 Argo CD source가 아니다 — 변경 후 `./k8s/deploy.sh`로 다시 적용
- 서비스는 CI가 발행한 `<service>-deploy` OCI 아티팩트를 서비스별 Application이 동기화

GitLab이 `/`를 사용하므로 UI는 `https://<tailscale-hostname>/argocd` 하위 경로로 노출한다
(`server.insecure`, `server.rootpath`/`server.basehref` = `/argocd`, TLS는 Traefik이 종단).

**초기 admin 비밀번호:**

```bash
kubectl get secret argocd-initial-admin-secret \
  -n argocd -ojsonpath='{.data.password}' | base64 -d; echo
```

스크립트가 자동으로 OpenBao `infra/argocd`에도 저장한다.

## 완료 후 상태 확인

```bash
kubectl get pods -A
kubectl get pods -n traefik
kubectl get pods -n argocd
kubectl -n argocd get appprojects,applications
kubectl get pods -n gitlab   # GitLab 사용 시
```
